# ATR Data

The complete data package for the ATR project is hosted on Hugging Face:

**Dataset repository:** [SII-minxiyu/ATR](https://huggingface.co/datasets/SII-minxiyu/ATR/)

The package contains 517 files (approximately 75.9 GiB) and preserves the directory structure used by the training and evaluation workflows in this repository.

## Contents

- **Full and subset datasets:** the full data collections and curated subsets used in different training and evaluation settings.
- **Multi-teacher labeled data:** labels and predictions generated by multiple teacher models, including CHGNet, MACE, PET-MAD, and SevenNet variants.
- **ATR training data:** merged databases and tabular data used to train and validate the ATR model.
- **Materials Project data:** Materials Project r2SCAN data, conversion utilities, split definitions, and train/validation/test identifiers.
- **Multiple test datasets:** standard test, held-out test, and system-specific evaluation datasets for assessing model accuracy and transferability.
- **Molecular-dynamics data:** AIMD/MLMD structures, trajectories, run configurations, metadata, and evaluation outputs for the included material systems.

## Directory overview

```text
data/
├── ATR-data/                    # ATR training and validation data
├── subset/                      # Curated full-data subsets
├── teacher-distillation label/ # Multi-teacher labels and predictions
├── mp-r2scan/                   # Materials Project r2SCAN data and splits
├── MD/                          # AIMD/MLMD data and evaluation workflows
├── train.extxyz                 # Training structures
├── test.extxyz                  # Standard test structures
└── heldout_test.extxyz         # Held-out test structures
```

## Download

Install the Hugging Face CLI and download the dataset into this directory:

```bash
hf download SII-minxiyu/ATR --repo-type dataset --local-dir data
```

Keep the downloaded file names and directory structure unchanged so that the repository scripts can resolve their expected data paths.

## Repository policy

GitHub stores the source code, scripts, model weights, configuration files, and documentation. The complete datasets, trajectories, databases, labels, and generated evaluation data are maintained in the Hugging Face dataset repository.
